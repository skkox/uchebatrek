# УчебаТрек

Веб-приложение для сопровождения обучения с возможностью загрузки заданий.
Разработано в рамках учебной практики (ПМ.08 «Разработка дизайна веб-приложений»).

Студент видит курсы, задания и сроки, загружает выполненные работы и получает оценки.
Преподаватель публикует задания, проверяет работы, выставляет оценки и возвращает работы на доработку.

## Возможности

**Студент**
- вход и регистрация;
- главная страница со сводкой: что нужно сдать, что на проверке, средний результат;
- курсы с прогрессом сдачи, поиск, фильтр по статусу и сортировка заданий;
- загрузка работы файлом (выбор или перетаскивание), проверка формата и размера до отправки;
- скачивание, замена и отзыв своей работы, пока она не проверена;
- статусы: «К сдаче», «На проверке», «На доработке», «Проверено», «Просрочено»;
- оценки с комментариями преподавателя, экспорт в CSV;
- календарь сроков по месяцам, уведомления, профиль, смена пароля.

**Преподаватель**
- создание курсов и заданий (срок, максимальный балл, допустимые форматы, приём после срока);
- редактирование и удаление заданий;
- проверка работ: скачивание файла, оценка, комментарий, возврат на доработку;
- журнал успеваемости по курсу и экспорт в CSV;
- уведомления о новых работах.

**Общее:** тёмная и светлая темы, адаптивная вёрстка (ПК, планшет, смартфон), управление с клавиатуры.

## Запуск

Сборка не нужна. Достаточно открыть файл `index.html` в браузере
или опубликовать папку на GitHub Pages (Settings → Pages → Deploy from a branch → main).

```
index.html            страница-оболочка, подключение стилей и скриптов
assets/               логотип и значок сайта

  variables.css       цвета, шрифты, размеры; тёмная и светлая темы

  pages.css           стили отдельных страниц
  responsive.css      адаптивность

  utils.js            даты, форматирование, скачивание файлов
  seed.js             демонстрационные данные
  db.js               работа с данными (localStorage)
  fileStore.js        хранение загруженных файлов (IndexedDB)
  auth.js             вход, выход, регистрация
  router.js           маршрутизация по адресу после «#»
```

## Ограничения

Это учебный прототип без серверной части:
- данные и файлы хранятся только в браузере, где открыто приложение (localStorage и IndexedDB), другие пользователи их не видят;
- пароли хранятся открытым текстом, поэтому настоящий вход и защита данных потребуют сервера;
- уведомления работают внутри одного браузера.

Для промышленного использования нужно добавить серверную часть (API и база данных), хранение файлов на сервере и защищённую авторизацию.
